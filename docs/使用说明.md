# 全能办公助手 · 使用说明

程序常驻系统托盘，五个页签对应四大功能与设置。
以下按页签说明操作方式、注意事项与常见问题。

---

## 通用操作

| 操作 | 说明 |
| --- | --- |
| 启动 | 双击 `全能办公助手.exe` |
| 关闭主窗口 | 默认**最小化到托盘**（不是退出）；可在「⑤ 设置与合规」页改为直接退出 |
| 重新打开 | 双击托盘图标，或右键托盘图标 → 打开主界面 |
| 托盘右键菜单 | 打开主界面 / 立即整理内存 / 立即同步作业 / 退出 |
| 未完成作业角标 | 托盘图标右下角红色数字，来自作业看板的未完成条数 |
| 状态栏 | 左下显示最近一次操作结果，右下显示索引概况与内存调度状态 |

---

## ① 网络访问优化（合规版）

> 页面顶部常驻合规边界说明。关闭「启用网络优化功能」开关后，本页不进行任何测速或配置写入。

### 1. 目标站点测速

点「开始测速」：对 GitHub（主站/API/打包下载/Release/raw/SSH-443）与 Steam（商店/社区/API/CDN/连接管理器）
共 12 个域名做 **DNS → TCP → HTTPS** 三段测量，并发 6 路，超时自动跳过。

- 「综合延迟」取 HTTP 往返（若可得），否则取 TCP 往返。
- 「偏慢」阈值默认 1500ms。
- 不可达的目标只如实展示，请通过官方渠道处理；本工具不提供任何绕过手段。

### 2. GitHub 镜像源管理

1. 在列表中选择镜像源（或选「自定义镜像前缀」并在下方填写完整前缀）。
2. 点「应用所选镜像」→ 确认后写入 `git config --global url.<镜像前缀>/.insteadOf https://github.com/`。
3. 想回到官方源：点「一键还原配置」，按最近快照恢复。

> 镜像为第三方只读副本，可用性与内容完整性请自行判断。

### 3. Git 配置优化向导

勾选需要的配置项（如 `core.longpaths`、`http.postBuffer`、`lowSpeedLimit` 等）→「应用选中的配置项」。

- 写入前**自动创建快照**（git 全局配置 + `~/.ssh/config` + 代理环境变量）。
- 「写入 SSH over 443 配置」会在 `~/.ssh/config` 追加把 `github.com` 指向 `ssh.github.com:443` 的段落，
  适用于屏蔽 22 端口的网络；已有相同配置时不会重复写入。

### 4. 克隆命令向导

填写仓库地址 → 选择是否浅克隆/稀疏检出 → 「生成克隆命令」，可直接复制到终端执行。
「测量官方源 / 镜像源耗时」用 `git ls-remote`（只读引用列表，不下载仓库对象）分别计时，用于对比。

### 5. 代理设置引导（用户自备代理）

- 页面显示当前检测到的代理来源：Windows「Internet 选项」、`HTTP_PROXY`/`HTTPS_PROXY` 环境变量、
  WinHTTP 配置（**均为只读检测**）。
- 若你有自备代理，填入形如 `http://127.0.0.1:7890` 的地址 → 「写入配置」：
  写入 git 全局 `http.proxy`/`https.proxy` 与**用户级**环境变量，写入前自动快照。
- 「重新检测」刷新显示；「一键还原配置」按快照恢复（包括清除本次新增的环境变量）。
- 本工具不内置、不启动任何代理或隧道进程，也不改动系统代理设置。

### 6. 包管理器镜像

npm / pip / Maven / Go 的镜像设置命令以文本形式给出，需自行复制执行（程序不代你执行第三方命令）。

## ② 学习通作业

### 当前模式

页面顶部显示「在线模式（已配置平台端点）」或「本地/导入模式（未配置平台端点，不访问学习通服务器）」。

学习通未提供公开开放接口，其私有接口端点需实机抓包确定。本程序提供可插拔接入点：

1. 到「⑤ 设置与合规」→「学习通平台适配器」填写平台地址、接口路径与字段映射 → 保存 → 重启程序。
2. 回到本页用手机号/学号 + 密码登录（凭据经 Windows DPAPI 加密，仅存本机）。
3. 点「立即同步」，或开启「自动同步」（间隔最低 10 分钟，失败按指数退避）。

未配置端点时，程序**明确降级为本地/导入模式**，不发起任何请求，也不返回任何伪造数据。

### 本地/导入模式怎么用

1. 把作业整理成 CSV（UTF-8）：

   ```csv
   课程,标题,截止时间,状态
   高等数学,第三章习题,2026-11-01 23:59,未提交
   大学英语,听力作业,2026-11-03 12:00,已提交
   ```

   JSON 亦可（数组，字段 `course/title/deadline/status`，可选 `id`）。
2. 点「导入作业计划（本地模式）」选择文件。
3. 看板即刻显示；「导出 CSV」可把当前看板导出备份。
4. 想快速体验看板与提醒，可点「添加示例作业（演示看板与提醒）」，确认后写入 2 条标记为“示例数据”的作业。

### 看板

- 「按课程分组」/「按截止时间排序」两种视图；「只看未完成」过滤。
- 每行左侧复选框是**本地完成标记**，与平台状态合并展示：
  本地已完成 > 已提交 > 已逾期 > 未提交 > 状态未知。
- 24 小时内截止且未完成的条目会高亮（`IsUrgent`）。

### 提醒

- 默认在截止前 **24 / 6 / 1 小时**提醒，可在本页「提醒档位（小时）」改为任意小时数（逗号分隔）后保存。
- 提醒通过系统托盘气泡通知送达；**同一作业同一档位同一截止时间只提醒一次**（持久化去重）。
- 「逾期也提醒」可关闭。
- 右上角「退出登录」立即清除本机凭据密文。

### 同步日志

右侧「同步日志」页签显示每次同步的时间、结果、课程/作业条数、耗时与错误说明，便于排查。

## ③ 磁盘管理与清理（核心功能）

### 1. 扫描

1. 在卷卡片上勾选要扫描的磁盘（默认全部固定磁盘；也可在设置页固定扫描范围）。
2. 选择「仅系统盘」/「增量扫描」/「扫描后识别内容」。
3. 点「开始扫描」（首次建议用「全量重扫」建立索引）。

扫描**全程只读**，不修改任何文件；工作线程使用低于正常的优先级，后台静默执行；
工具条下方实时显示遍历数量、累计大小、速率与用时。可随时「中止扫描」。

- 全量扫描会重建所选卷的索引，并清除数据库中已不存在的陈旧条目。
- 增量扫描基于目录指纹（mtime）比对，未变化子树整棵跳过，速度显著更快。

### 2. 三段式浏览

- **左侧盘符树**：盘符为根节点，懒加载展开（展开时才查询数据库）。目录显示“名字 + 大小”，
  未识别文件带 ⚠ 标记。悬停可见完整路径。
- **中部文件详情与内容摘要**：
  - 图片显示 ≤128 像素缩略图；
  - 文本显示标题、编码、行数与正文摘录；
  - 音视频显示时长、分辨率、码率；
  - Office 文档显示标题/作者、正文开头、段落数、工作表名或幻灯片页数；
  - PDF 显示标题/作者/页数估计；压缩包显示条目数、解压后大小与顶层目录；
  - 未识别文件显示文件头十六进制，便于人工判断。
  - 同时显示大小、类型、修改时间、风险等级与“内容摘要”。
- **右侧操作面板**：打开 / 在资源管理器中定位 / 复制路径 / 重命名 / 移动到… / 删除到回收站。

### 3. 拖拽（本工具的核心交互）

- 把**文件或文件夹拖到左侧目录节点** = 移动（同名冲突时弹窗询问，可选择先覆盖或取消）。
- 把**文件或文件夹拖到右下角垃圾桶区** = 删除（**进回收站，可恢复**）。
- 从「未识别文件区」表格可多选后拖拽。
- 保护规则：不能把目录拖进自己的子目录；受保护路径会被拦截并说明原因。

### 4. 未识别文件区（页签）

内容无法判定的文件集中在此（按体积降序），显示文件名、大小、所在目录、**文件头十六进制**与修改时间。
勾选后可「删除已勾选」（仍走误删防护 + 回收站 + 二次确认）。

### 5. 一键清理（页签）

1. 点「生成预览」：按「安全级」规则匹配候选（临时文件、缓存、回收站、旧安装包、崩溃转储、
   浏览器缓存、开发工具缓存等），显示条数、合计大小、命中规则与完整路径。
2. 核对后用「全选 / 全不选」与单条勾选调整，面板实时显示“已选 N 项，预计释放 X”。
3. 点「执行清理（进回收站）」→ 二次确认后执行。

> **只处理安全级清单**。谨慎级（用户文档目录大文件、下载目录归档、重复文件）与危险级
> （系统目录、Program Files、可执行体、脚本、被占用文件）永不进入该清单。
> 清理后「未识别」与「索引」统计会自动刷新。

### 6. 重复文件分析（页签）

点「开始分析（MD5 校验）」：先按大小分组，再对组内文件计算 MD5 确认为真正重复。
每组默认**保留最早修改的一份**，其余默认勾选为“可删除副本”。
「删除已勾选副本」→ 二次确认 → 进回收站。

> 重复文件属于「谨慎级」，只提示不自动清理，请自行确认。

### 7. 安全机制（务必了解）

- 所有删除调用 `IFileOperation` + `FOFX_RECYCLEONDELETE`，**进回收站可恢复**；
  回收站不可用时程序会明确报错，不会静默改为永久删除。
- Windows / Program Files / ProgramData / 用户配置目录 / 卷根系统目录默认保护，删除会被硬拦截。
- 单次删除 ≥20 个条目或涉及用户文档目录时，需要输入「确认」二字。
- 全部操作写入操作日志（`operation_log` 表）与审计日志（`logs\operations.log`，界面不提供删除入口）。

## ④ 智能资源管家

> 目标：不关闭后台应用的前提下，按调度自动整理内存与优先级。**不结束任何进程。**

### 实时状态

- 物理内存进度条与使用量、可用量、已提交量；
- 待机缓存（Standby）大小；
- 系统空闲时长（无键盘鼠标输入）；
- 权限提示：普通权限下待机列表清理会被跳过。

### 自动清理策略

| 配置 | 说明 |
| --- | --- |
| 启用自动清理 | 总开关；关闭即停止调度线程 |
| 周期执行 | 每 N 分钟执行一次 |
| 固定时间（cron） | 5 段表达式：分 时 日 月 周；支持 `*/n`、`a-b`、`a,b,c` 与 `@hourly/@daily/@weekly/@monthly` |
| 阈值触发 | 内存占用高于 X% **且** 系统空闲超过 Y 分钟时执行（另有 5 分钟冷却） |
| 清理 Standby 待机列表 | 需管理员权限，默认关闭；可选“仅低优先级待机列表” |
| 降低低交互进程优先级 | 对空闲超过设定时长的进程降为“低于正常”，清理结束后恢复原值 |

改完点「保存并生效」：启用则自动启动调度线程，停用则立即停止。

### 执行与报告

- 「立即整理内存」手动执行一次（与自动调度共用同一套逻辑）。
- 「进程工作集排行」列出前 40 个进程的工作集、私有内存、CPU 时间、启动时长与**本次是否参与整理**
  （前台/系统关键/白名单会标记为“豁免”）。
- 「清理报告」逐次记录：时间、触发方式、释放物理内存、待机缓存、耗时与明细
  （压缩/跳过/失败进程数、清理前后内存对比）。
- 面板底部如实说明技术边界：工作集压缩属于短期整理，被换出的空闲页面会按需重新调入，
  释放量是即时值，不承诺持续低占用。

### 进程白名单

默认已包含系统关键进程（`System`、`csmod`、`svchost`、`dwm`、`explorer` 等）与常用前台应用
（编辑器、浏览器、办公软件、输入法相关进程等）。
在「进程白名单」输入框追加进程名（逗号分隔，可带 `.exe`）→「保存白名单」。默认项始终保留。

## ⑤ 设置与合规

### 磁盘扫描范围与性能

- 勾选参与扫描的卷；「仅扫描系统盘」；「扫描后执行内容识别」；「默认使用增量扫描」。
- 并行度建议等于 CPU 物理核心数（1–32）。扫描线程始终使用低于正常的优先级。

### 托盘行为与后台服务

- 关闭窗口时最小化到托盘；托盘角标；启动后自动运行资源管家调度；启动后自动同步学习通作业。

### 学习通平台适配器

填写平台地址、登录/课程/作业接口路径、字段名与数组路径。保存后重启程序生效。
「重置为本地模式」清空端点配置。

### 数据与隐私

- 显示数据目录、数据库文件、审计日志、凭据状态、索引概况与版本信息。
- 「打开数据目录 / 打开日志目录」直接在资源管理器中定位。
- 「清除学习通凭据」立即删除 DPAPI 密文文件。
- 「清除全部本地数据」删除索引、课程作业、日志、设置、规则与凭据（不影响磁盘上的任何文件）。
- 隐私承诺：全部数据仅存本机，不上传任何文件路径、文件内容与日志。

### 合规红线回归自检

点「重新运行自检」，程序扫描自己已部署的二进制文件，确认其中**不存在**：
修改 hosts、写入系统代理、安装驱动或过滤规则、建立 VPN/隧道的能力，
并列出本程序允许的全部系统写入点。结果可直接复制留档。

### 运行日志

显示最近 400 行运行日志，「刷新日志」重新读取。

## 常见问题

**问：扫描会不会动我的文件？**
不会。扫描是纯只读操作；只有你明确确认的删除/移动才会修改文件系统，且删除一律进回收站。

**问：为什么有些文件删不掉？**
命中误删防护（系统目录、程序目录、可执行体/脚本、白名单、卷根系统目录）。这是设计目标之一。
界面会给出具体拦截原因。

**问：一键清理为什么是空的？**
清单只收录“安全级”条目。请先完成一次扫描；若系统较干净，确实可能为空。

**问：为什么扫描速度比预期慢？**
机械硬盘、海量小文件、杀毒软件实时扫描都会显著影响。可降低并行度、只扫系统盘，
或先用增量扫描。界面显示的实时速率与用时才是真实值。

**问：内存整理释放不多？**
工作集压缩是短期整理，被换出的空闲页面会按需重新调入；不结束进程的前提下回收存在客观上限。
报告如实展示清理前后对比，请以此为准。

**问：学习通能不能直接登录同步？**
需要你提供抓包得到的接口端点（在设置页填写）。未配置时使用本地/导入模式，功能完整但不访问平台。

**问：配置文件改坏了怎么办？**
「① 网络访问优化」页的「一键还原配置」按最近快照恢复 git 配置、`~/.ssh/config` 与代理环境变量。

**问：怎么彻底卸载？**
运行 `安装.ps1 -Uninstall`，或删除 `%LOCALAPPDATA%\全能办公助手` 目录与程序目录。
（便携模式下数据在程序目录的 `data` 子目录，随程序目录一起删除即可。）
