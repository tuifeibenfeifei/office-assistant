# 全能办公助手插件 · 功能说明

> 本文档用于直接交给 AI 完成开发与迭代，聚焦"做什么、怎么做、边界在哪"。本文档为更新版：已删除学习通功能，重新设计磁盘管理 UI，并列入已知问题修复项。

## 一、当前状态

- 已有可运行版本，功能一（网络访问优化）已实现可用。
- 功能二（学习通作业管理）已确认删除，不再开发，本文档已移除相关内容。
- 现有界面过于复杂、不符合人机工学（人体工程学），需按"UI 设计规格"整体重做，改为简洁、清晰、科技感且更有质感的风格。
- 存在已知问题：程序退出后无法再次启动，提示"程序已在运行，可在系统托盘查看"，但系统托盘没有图标（详见"已知问题与修复要求"）。

## 二、项目概述

开发一款 Windows 10/11（64 位）桌面办公辅助插件，系统托盘常驻，包含三大功能：

1. 网络访问优化（GitHub / Steam 社区加速）；
2. 磁盘可视化管理与一键清理（核心功能，含全新 UI）；
3. 智能资源管家（定时自动清理内存）。

所有数据仅本地存储，不上传。目标用户为普通电脑用户，软件计划上架软件商城分发，因此界面必须极简、无说明文字、一看就会用；功能使用说明统一收纳在"设置 → 使用说明"中，不占用主界面。

## 三、UI 设计规格（最重要，逐条落实）

### 3.1 设计总则

**第一原则：极度简洁 + 符合人机工学。** 每个界面只保留 2~4 个必要元素，主操作一眼可见；任何地方不出现功能说明文字、教程文案、菜单堆叠；所有说明性内容只存在于"设置 → 使用说明"。

**第二原则：科技感且更帅。** 在极简底子上做质感：深蓝渐变 + 玻璃拟态卡片 + 克制的辉光 + 精致线性图标 + 细腻微动效。帅来自质感和光效，不来自堆元素。

### 3.2 视觉规范（统一色值）

| 项目 | 取值 |
|---|---|
| 窗口背景 | 深蓝→藏蓝垂直渐变：`#0A1633 → #122B57` |
| 背景装饰 | 极淡蓝色光晕 / 星点（透明度 ≤8%，不抢主体） |
| 卡片底色 | 半透明白 `rgba(255,255,255,0.06)` |
| 卡片边框 | 1px 半透明白 `rgba(255,255,255,0.18)`，圆角 16px |
| 卡片阴影 | `0 8px 32px rgba(0,0,0,0.35)` + 轻微内发光 |
| 主操作绿 | `#22E584`，辉光 `0 0 16px rgba(34,229,132,0.5)` |
| 科技蓝（选中/链接） | `#3B82F6` |
| 主文字 | 白 `#FFFFFF` |
| 辅助文字 | 浅蓝 `#9BB6E5` |
| 弱化文字 | 灰蓝 `#6B7FA3` |
| 字体 | 微软雅黑 / 思源黑体；标题 20–22px 粗体，正文 14–16px，辅助 12px |
| 图标 | 统一线性图标，描边 1.5–2px，圆角端点，颜色继承文字色 |
| 圆角 | 卡片 16px，按钮 10–12px，开关/小元素 8px |
| 间距 | 页面边距 32px，元素间距 16–24px，同类元素间距均匀 |

### 3.3 动效与反馈规范（克制，不花哨）

- 所有过渡 150–250ms、ease-out；禁止循环动画、弹跳、炫光扫过等装饰性效果。
- 卡片悬停：上浮 2px + 边框辉光变亮；点击有按压反馈（缩小 0.98）。
- 主按钮（绿色）：常态带柔和辉光，按压时辉光增强、瞬间反馈。
- 开关切换、节点展开收起：150ms 缓动，禁止生硬跳变。
- 扫描/清理进行中：用圆环或进度条旋转表示；完成后数字更新并有轻量"完成"反馈。
- 每次用户操作必须有即时视觉反馈（高亮、变色、位移），操作结果必须可见。
- 页面切换：统一 200ms 淡入淡出；返回时保持原状态（不重置画布位置与展开层级）。

### 3.4 各界面规格（逐屏，详细）

#### 界面 1：主界面（极简入口）

窗口默认尺寸 900×600，可等比缩放，最小 800×560；背景为深蓝→藏蓝垂直渐变，顶部约 1/3 区域散布极淡的蓝白色星点与光晕（透明度不超过 8%，仅作氛围，不干扰阅读）。

- **标题区**：顶部居中一行软件名"全能办公助手"，22px 白色粗体，字距 2px，文字带非常轻微的白光（`0 0 12px rgba(255,255,255,0.2)`）；标题右侧约 24px 处放一个 20px 白色线性齿轮图标（描边 1.8px、圆角端点），点击进入设置页，悬停时图标变亮绿。
- **功能卡片区**：窗口垂直中线略偏上，水平排列三个完全等大的玻璃卡片，每张 180×200，卡片间距 24px，左右居中。卡片材质：半透明白底、1px 半透明白细边框、16px 圆角、柔和外阴影与轻微内发光。卡片内容从上到下为：44px 白色线性图标（描边 1.8px、带极淡辉光）、下方 12px 空隙、一行 16px 白色名称，无任何副标题或说明。三张卡片分别是：闪电图标 + "网络加速"；文件夹图标 + "磁盘管理"；风扇图标 + "内存清理"。
- **状态与交互**：默认态如上；悬停时卡片上浮 2px、边框辉光提亮；按下缩小至 0.98；点击卡片以 200ms 淡入进入对应功能页。
- **底部**：居中一行 12px 灰蓝色文字"版本 1.0"。
- 全界面无菜单栏、无侧边栏、无通知区、无任何说明文字。

#### 界面 2：网络加速

窗口默认 900×600；背景与主界面一致。左上角一个 20px 白色线性返回箭头，悬停变亮绿，点击返回主界面；顶部居中标题"网络加速"，22px 白色粗体。

- **加速按钮**：窗口正中央一个大号正圆形按钮，直径 120px，底色为亮绿 `#22E584`，常态辉光 `0 0 24px rgba(34,229,132,0.5)`；中心一个 48px 白色闪电图标（实心）。悬停辉光增强到 0.7 并略微放大到 1.02；按下缩小到 0.94；点击后执行一键加速，执行期间按钮做轻量呼吸（透明度 0.85↔1，周期 1.2s，无限直到完成），完成后恢复常态。加速过程无任何文字提示，避免噪音。
- **状态条目**：按钮正下方，两条状态条目垂直排列、左右居中、行高 56px，行与行之间无分隔线。每行从左到右：10px 状态圆点（已连接/正常 = 亮绿实心带辉光；未连接/待测 = 灰蓝实心；失败 = 红色实心）、右侧 12px 空隙、14px 白色平台名、再右侧自动右对齐的 14px 浅蓝色等宽数字或状态文字。示例：第一行 绿点 + "GitHub" + "12.4 MB/s"；第二行 灰点 + "Steam" + "未连接"。
- 全界面无菜单、无说明文案、无多余控件，一个按钮两行状态即是全部。

#### 界面 3：磁盘清理（核心界面，画布式，最详细）

窗口默认 1200×760，可拖边缩放、可最大化；整个窗口内容是一个可平移、可缩放的无限自由画布，所有节点以矢量方式渲染，缩放任意倍率都保持清晰。

- **画布交互**：按住画布空白处拖拽 = 平移，光标变为抓取手；鼠标滚轮 = 缩放，范围 50%–200%，缩放锚点跟随鼠标位置；画布左上角和右上角各有一个 36px 圆形半透明按钮，内部分别为白色"+"和"−"符号，点击缩放一格（±25%），用于不习惯滚轮的用户。平移与缩放全程流畅跟手（目标 60fps），松手无回弹。
- **盘方块**：程序启动后自动枚举盘符，N 个盘显示 N 个大方块，默认按盘符字母从左到右排列，间距 32px，垂直居中。方块为 160×160 正方形玻璃卡片：20px 圆角、半透明白底、1px 白边框、柔和阴影与内发光；左上角一个 24px 白色粗体盘符字母（如"C"）；方块内部下方距底边 20px 处一条白色细圆角进度条（宽 100px、高 6px），已用空间以亮绿发光填充，填充宽度 = 已用/总容量比例；进度条右侧 12px 浅蓝等宽容量数字（如"128GB"）。方块本身可拖动调整摆放位置：拖动时半透明跟随并带投影，松手吸附到最近的网格位。
- **绿色小圆圈（展开点）**：每个盘方块右侧边缘正中位置，一个 16px 亮绿实心发光圆（辉光 `0 0 10px rgba(34,229,132,0.6)`），是唯一的展开/收起入口。点击后 180ms 缓动展开：从圆圈向外放射出 3–5 条浅蓝色贝塞尔曲线（1.5px、透明度 0.7），每条线末端连接一个小方形节点；再点一次全部收起，曲线与节点 180ms 收回。展开点常显，提示该盘可展开。
- **分支节点（小方形 = 文件夹）**：每个节点为 64×64 小方形，12px 圆角，半透明白底 + 1px 白细边框 + 28px 白色文件夹线性图标；节点之间用同款浅蓝曲线连接，逐级向右下延伸，形成树状分支。任意文件夹节点可继续点开下一级（懒加载，点开才扫描展开）；超过 6 层或同级超过 50 个节点时不再自动展开，节点上出现一个小按钮"继续展开"。
- **内容摘要**：点击任意文件夹节点，在其右侧附近浮出一张 280×200 摘要卡（200ms 淡入，点击画布空白处关闭）。摘要卡内容：文件数量、总大小、文件类型占比（一条 4 色小色条，按文档/图片/视频/其他分类着色）、3~5 个大文件的名称与大小、最近修改时间。摘要数据来自扫描识别结果；内容无法识别的文件夹在摘要卡顶部标一个灰色"待判断"角标。
- **扫描深度**：扫描时不仅读文件夹名，要深入扫描内部内容并识别摘要（文档取标题/前 N KB 文本摘要、图片生成缩略图、音视频读时长与分辨率）；扫描只读不修改。
- **拖拽搬运**：按住任意小方形节点可拖拽：拖动时节点半透明并带投影跟随光标；拖到另一个盘方块或文件夹节点上时，目标高亮绿色边框并轻微放大；松手弹出确认卡（深蓝玻璃卡："移动到" + 目标路径 + "确认/取消"），确认后执行移动；目标存在同名文件时提示冲突选项（替换/跳过/改名）；权限不足时明确提示"需要管理员权限"。取消则节点回到原位。
- **拖拽删除**：画布右下角固定悬浮一个垃圾桶（56×56，白色筒形线条 + 亮绿圆形底 + 辉光），不随画布平移，始终可见。节点被拖入垃圾桶区域时，垃圾桶放大到 1.15 倍且辉光增强，出现一道吸入光效；松手弹出确认卡："移入回收站？" + "确认/取消"，确认后调用系统回收站删除（可恢复），节点从画布消失并播放 150ms 淡出。
- **未识别文件区**：画布左下角一个不显眼的小按钮"待判断文件"（14px 灰蓝文字，右侧一个数字角标显示数量）；点击打开半屏抽屉列表，按路径分组展示所有无法识别内容的文件（文件名、完整路径、大小），每行右侧三个小操作：保留（白）、删除（绿，进回收站）、移动（蓝，选目标路径）；列表底部一行说明"这些文件无法自动识别，请自行判断"。
- **一键清理**：画布右上角一个亮绿色按钮"一键清理"（36px 高、带辉光）。点击弹出预览窗：按分类列出可安全删除的清单（临时文件、缓存、旧安装包、回收站内容、浏览器缓存），每类显示数量与可释放空间，底部合计预估释放量；确认后逐类执行，完成时按钮上方浮出绿色对勾 + 一行白字"已释放 XX MB"。
- **扫描反馈**：盘方块扫描进行中，方块中央显示一个发光进度环（白绿渐变，匀速旋转），完成后变为绿色对勾并常驻；已扫描完成的盘可以立即展开查看，无需等待全盘结束。
- 全界面无说明文字、无菜单栏、无状态栏。

#### 界面 4：内存清理

窗口默认 900×600；背景与主界面一致。左上角白色返回箭头；顶部居中标题"内存清理"，22px 白色粗体；右上角一行 12px 灰蓝文字"自动清理已开启"，左侧一个 8px 亮绿发光圆点表示开启状态（关闭时文字为"自动清理已关闭"、圆点变灰）。

- **结果圆环**：窗口正中央一个大号白色细线圆环（外径 200px、线宽 2px），环心为亮绿色大号粗体数字（40px，展示累计已释放内存 MB 数，如"356"），数字下方一行 13px 浅蓝小字"MB 已释放"。清理执行中圆环以 1 秒一圈匀速旋转并带绿色流光；完成后圆环恢复静态，数字以滚动动画更新到新值。
- **清理按钮**：圆环正下方 24px 处，一个 160×40 亮绿圆角矩形按钮（12px 圆角、常态辉光），按钮内白色粗体"立即清理"。悬停辉光增强；按下缩小 0.97；执行中按钮变为灰蓝禁用态、文字变为"清理中…"；完成后恢复并短暂变亮。
- 全界面只有标题、圆环与数字、一个按钮、一行状态，无列表、无说明、无多余控件。

#### 界面 5：设置（含"使用说明"入口）

窗口默认 900×600；背景与主界面一致；顶部居中标题"设置"，22px 白色粗体。

- **左侧导航**：宽 160px，竖向排列三项文字，15px，行高 48px，左对齐并留 16px 内边距，依次为"常规""使用说明""关于"。当前选中项为亮绿 `#22E584`，其余白色；悬停项变浅蓝；点击切换右侧内容，切换 150ms 淡入。导航项无图标，只有文字。
- **右侧面板（常规）**：玻璃卡片（16px 圆角、半透明白底、1px 白边框），内边距 24px，竖向排列三行设置条目，行高 56px：每行左侧 15px 白色条目名，右侧一个 44×24 圆形拨动开关（开启：亮绿底 + 白色圆点滑至右侧 + 轻微辉光；关闭：半透明白底 + 白圆点滑至左侧）。三行依次为"开机启动""自动清理内存""常驻托盘"。行与行之间只有 1px 浅蓝半透明分隔线，条目内无任何说明文字。
- **使用说明页**（从左侧"使用说明"进入）：全页可滚动图文。每一条说明 = 一行 16px 白色粗体小标题 + 一段 14px 白色正文（大白话，一句话讲清一个操作）+ 一张示意图（界面截图或简单图示），条与条之间留 24px 间距。文案示例："点这里加速 GitHub""拖文件夹到垃圾桶就是删除，可以恢复""点击绿色圆圈展开盘里的文件夹"。这是全软件唯一出现说明文字的地方，措辞必须普通用户能看懂，不出现技术术语。
- **关于页**：居中展示软件名"全能办公助手"、版本号"版本 1.0"、一行 14px 灰蓝简介"本地办公辅助工具，数据不上传"。

### 3.5 通用组件规格

- **按钮**：三种——主按钮（亮绿底白字、常态辉光）、次级按钮（半透明白底 + 1px 白边框 + 白字）、危险按钮（红 `#E5484D` 底白字，用于"永久删除"这类不可恢复操作）。高度 36–40px、圆角 10–12px、文字 14–15px 粗体，禁用态统一灰蓝 40% 透明。
- **确认弹窗**：深蓝玻璃卡片（16px 圆角、半透明白底、1px 白边框、大阴影），居中于当前窗口；标题 16px 白粗体 + 正文 14px 白字 + 底部两个按钮（确认=亮绿、取消=次级）；弹窗 150ms 淡入，点遮罩外可取消。所有删除/移动类操作必须经过确认弹窗。
- **开关**：44×24 圆角胶囊，见界面 5 描述；切换 150ms 缓动，带按压反馈。
- **进度环**：36px 发光圆环，白绿渐变，用于扫描与清理过程；完成后变绿色对勾。
- **图标集**：全部使用同一套线性图标风格（描边 1.8px、圆角端点、镂空），仅以下图标：齿轮、返回箭头、闪电、文件夹、风扇、垃圾桶、加号、减号、对勾、圆点；不引入第三方图标库的多余样式。

### 3.6 托盘图标与启动

- **托盘图标**：程序运行期间系统托盘必须始终显示图标。图标设计：16×16 深蓝圆角底 + 白色闪电与齿轮组合线标，辨识度高；图标常驻不消失。
- **托盘交互**：左键单击打开/唤起主窗口；右键弹出小菜单：打开主界面 / 使用说明 / 退出。退出菜单项点击后完全退出程序并释放托盘图标。
- **启动**：程序启动直接进入主界面；启动期间若有扫描任务在后台进行，主界面磁盘卡片显示进度环，不阻塞其他功能。

## 四、功能说明

### （一）功能一：网络访问优化（GitHub / Steam 社区加速）【已可用】

**需求**：GitHub 仓库克隆慢、Steam 社区访问慢，需要合规加速。

**功能点**：
- 对 GitHub、Steam 常用域名做连通性测速并展示结果。
- GitHub 镜像源管理：内置公开镜像清单，一键切换 git 克隆前缀。
- Git 配置优化向导：生成 SSH over 443、浅克隆、稀疏检出等建议配置。
- 代理设置引导：检测系统代理；用户自备代理时写入 git 与系统代理配置，提供一键还原。
- 加速效果报告（可选）：加速前后测速对比。

**合规红线（必须遵守，不可实现以下任何一项）**：
- 不实现任何绕过网络管理措施的功能（如修改 hosts 绕过访问限制、内置代理/VPN、针对受限资源的自动访问）。
- 只做镜像切换、测速、配置优化等合法手段；无法合法直连的目标仅提示用户自行处理。
- 依据《网络安全法》（2016年通过，2017年施行，2025年修正）与《计算机信息网络国际联网管理暂行规定》（1996年国务院令第195号发布，2024年第二次修订）。

**验收**：可直连场景克隆加速 ≥2 倍；所有写入配置可一键回滚；不修改 hosts、不驻留代理进程。

### （二）功能二：磁盘可视化管理与一键清理（核心功能，UI 全新设计）

**需求**：
- 自动检测电脑上有几个盘，有几个盘就显示几个"盘方块"；
- 每个盘方块可展开，看到里面的文件夹分支；
- 文件夹节点可继续点开，看到扫描出的文件夹主要内容（不只是文件夹名，而是文件夹内的实际内容）；
- 拖动方形节点可实现文件夹搬运；
- 拖动方形节点到垃圾桶区域可实现删除（先进回收站，可恢复）；
- 保留一键清理与未识别文件区能力。

**UI 设计（按 3.4 界面 3 的规格实现）**：
- 主界面：蓝色科技感背景（深蓝/科技蓝渐变），白色文字，绿色作为状态与可操作指示。
- 盘符检测：程序启动时自动检测所有盘符数量（例如检测到 C、D、E 三个盘，就显示 3 个方块），方块显示盘符、总容量、已用、剩余。
- 盘方块：每个盘对应一个大方块；方块右侧有一个发光绿色小圆圈，点击绿色圆圈展开分支。
- 分支节点：展开后出现的每个分支是一个小方形，对应一个文件夹；文件夹节点可继续点开，展示扫描出的该文件夹主要内容（内部文件列表、文件类型、关键文件、内容摘要）。
- 扫描深度：扫描时不仅要读取文件夹名称，要深入扫描文件夹内部内容并识别摘要（文档标题/文本摘要、图片缩略图、音视频信息等）。
- 拖拽搬运：拖动方形节点（文件夹）到目标位置或另一个盘方块，实现文件夹搬运（移动）；冲突与权限要提示。
- 拖拽删除：拖动方形节点到垃圾桶区域，二次确认后移入回收站（可恢复）。
- 未识别文件区：内容无法识别的文件单独归类展示，由用户手动判断保留/删除/移动（保留此能力，并按统一科技感风格呈现）。
- 一键清理：仅对"可安全删除"清单执行，先预览并估算释放空间，再确认执行。

**技术实现要点**：
- 盘符枚举：调用系统 API（如 GetLogicalDrives）自动获取所有盘符。
- 画布：自由画布组件，支持拖拽平移与滚轮/按钮缩放（50%–200%），缩放锚点跟随鼠标。
- 扫描：多线程并行目录遍历（首扫），目录指纹快照（size + mtime）做增量比对；扫描只读，不修改文件。
- 内容识别：扩展名映射 + 文件头（magic bytes）双通道判定；文本读前 N KB 生成标题摘要；图片生成缩略图；音视频读元信息。识别失败的进未识别区。
- 节点 UI：卡片式节点（方块 + 绿色展开点 + 分支小方形）替代传统树状图；分支线用贝塞尔曲线；拖拽用前端拖拽层实现，节点拖出盘方块区域进入垃圾桶区即触发删除。
- 删除：风险三级（安全=临时文件/缓存/回收站/旧安装包/浏览器缓存；谨慎=用户文档目录大文件/重复文件；危险=系统目录/Program Files/运行中占用文件）。一键清理只处理安全级；删除统一调用回收站 API（IFileOperation），不物理删除。
- 参考项目：crystalidea/uninstall-tool（GitHub 官方发布归档仓库，无源码可复制；可借鉴"卸载残留扫描 + 删除前分级确认 + 结果报告"的产品思路）。

**验收**：启动自动识别盘符数量与实际一致；画布平移缩放流畅（60fps）；盘方块可展开、文件夹内容扫描摘要可见；全盘首扫（百万文件级）≤10 分钟、增量 ≤30 秒；拖动搬运与删除用例 100% 通过；高危目录删除全部被拦截、普通删除全部可恢复；识别覆盖率 ≥80%。

### （三）功能三：智能资源管家（定时自动清理内存）

**需求**：不关闭后台应用，按调度自动降低 CPU 与内存占用，无需用户手动点击。

**功能点**：
- 自动清理开关与调度：周期执行或固定时间执行（内置类 cron 调度器）。
- 阈值触发：内存占用高于阈值且系统空闲超过设定时长时自动执行。
- 工作集压缩：对非前台、非白名单进程执行 EmptyWorkingSet，前台进程豁免。
- Standby 列表清理：通过系统 API 回收待机缓存，需管理员权限，默认关闭可选开启。
- 进程优先级优化：降低长时间低交互进程的优先级，清理结束恢复。
- 高占用进程提示：仅提示，不自动结束进程。
- 清理报告：释放量、耗时、受影响进程清单。
- 进程白名单：用户指定永不触碰的进程。

**技术边界（如实实现，不夸大效果）**：
- 工作集压缩属于短期整理，系统按需会重新调入页面；
- 不结束进程前提下，内存回收存在客观上限；
- 验收以"释放量报告 + 前台无感"为准。

**验收**：阈值触发 5 次测试全部在预期条件触发；前台进程工作集不被压缩；单次清理释放 ≥200MB（视系统状态）；插件自身常驻内存 ≤120MB。

## 五、已知问题与修复要求（必须修复）

**问题现象**：程序退出后无法再次启动或登录，提示"程序已在运行，可在系统托盘查看"，但系统托盘并没有图标，导致用户无法再次进入使用。

**修复要求**：
- 单实例机制：退出程序时必须彻底释放单实例锁/互斥体，重新启动不受阻碍。
- 托盘图标：程序运行期间系统托盘必须始终显示图标（常驻）；托盘图标创建失败时要有兜底方案（如通过任务栏窗口或重新创建图标唤起主界面）。
- 退出逻辑：退出时完整销毁托盘图标、释放所有资源、结束所有后台进程与线程，确保无残留。
- 验证标准：退出后立即重新打开程序可正常进入；程序运行时托盘图标始终可见且可点击唤起主界面；反复退出-启动 10 次无失败。

## 六、技术实现约束

**技术栈（默认，可调整）**：
- 推荐：Tauri 2.x（Rust 核心）+ React/Vue 前端。理由：插件自身低占用；Rust 直接调用 Windows API（文件遍历、回收站、内存优化、网络）高效；WebView2 渲染画布节点 UI 成熟。
- 备选：C# WPF / .NET 8（Windows 原生，生态完整）。
- 不推荐 Electron（常驻内存 200MB+，与资源管家功能目标冲突）。

**分层架构**：
1. 用户界面层（React/Vue）：画布、盘方块、节点展开、拖拽、面板。
2. 桥接层：Tauri Command/IPC，白名单命令校验。
3. 核心服务层（Rust）：文件扫描引擎、内容识别引擎、清理与安全引擎、网络优化模块、资源管家与调度器。
4. 系统接口层：Windows API、文件系统、网络栈、SQLite 本地库。

**数据存储**：SQLite 单文件本地库（用户数据目录），核心表：
- files：path、parent、type、size、mtime、md5、risk_level、recognized、summary（按 parent 建索引）。
- file_types：ext、mime、magic、category。
- cleanup_rules：pattern、category、risk、enabled。
- settings：key、value。
- operation_log：ts、op、src、dst、result（操作审计）。

**权限设计**：扫描与查看免提权；删除、清理、内存优化按需 UAC 提权；提权后仅执行白名单命令。

**隐私**：全部本地存储；不上传任何文件路径、内容与日志；提供清除本地数据选项。
