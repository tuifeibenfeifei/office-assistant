# 变更记录

本项目遵循[语义化版本](https://semver.org/lang/zh-CN/)。

## [1.0.0] — 2026-10-07

首个版本。

### 新增

- **`office_text`**：JSON 格式化（缩进 0–8）与压缩、文本统计（字符/汉字/英文词/行/段/
  字节/阅读时长）、Base64 与 URL 编解码、命名风格互转（camelCase、PascalCase、
  snake_case、kebab-case、CONSTANT_CASE）。非法输入明确报错，不静默修改内容。
- **`office_scan`**：只读扫描目录并按体积给出文件夹排行与最大文件列表；
  逐级父目录累加体积；跳过无权限子目录；支持文件数上限并标注结果是否完整。
- **`office_clean`**：查看并清理系统公认的临时目录（用户临时文件、网络缓存、错误报告、
  缩略图缓存、DirectX / NVIDIA 着色器缓存、崩溃转储、最近使用记录）。
  **只清理白名单内的位置**，不接受任意路径；先 `preview` 再 `confirm=true` 执行；
  删除走回收站可恢复；每个目标在预览里标注"为什么删了没事"。
- **`office_memory`**：内存占用读数；可选整理非前台进程的工作集（不结束任何进程）。
- **侧边栏面板**：常驻内存占用率（≥75% 变黄、≥90% 变红），点开看总量/已用/可用；
  输入框下方一条紧凑指示。
- **只读接口** `GET /dsh-office-assistant/status`。
- 25 个自测用例（核心逻辑 18 + Host 集成 7），零依赖、无需构建。

### 安全设计

- 清理白名单写死在代码里，工具**不接受任意路径入参**——工具会被模型调用，
  不能让它有机会删掉用户没打算删的东西。
- 破坏性动作一律要求显式 `confirm=true`。
- 非 Windows 平台明确拒绝清理，不退化为永久删除。
- 识别失败、权限不足、文件被占用都跳过并如实报告，不静默忽略。
